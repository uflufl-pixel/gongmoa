# 부·처·청 등록

확인일: 2026-09-02. 행정안전부 기관별 기구도 7개 페이지의 기관명과 기관코드를 대조했다.

- 출처: https://www.org.go.kr/cop/bbs/getInstiChartList.do (pageIndex=1..7)
- 수 대조: https://www.org.go.kr/orgnzt/chart/viewEng.do (19부·6처·18청)
- 중앙행정기관 43개 및 중앙행정기관에 준하는 별도 2처(대통령경호처·고위공직자범죄수사처) 총 45개.
- 대검찰청은 공식 명단의 표기를 보존하고 검찰청을 검색 별칭으로 제공한다. 미시행 개편안의 기관을 현재 기관으로 등록하지 않는다.
- 기존 6개 중앙기관 ID는 유지한다. 나머지는 공식 기관코드 기반 ID로 기존 institutions 저장소에 중복 없이 삽입한다. 도메인·상급기관은 확인 없이 추정하지 않는다.
- GET /api/institutions 는 등록 및 직접 수집 상태를 읽는다. POST는 고정된 공식 목록만 멱등 등록하며 임의 URL·기관 정보를 받지 않는다.
- 기관 목록은 부·처·청 필터와 기관명 검색을 제공한다. 직접 수집 미연결 기관도 통합 출처에서 공고가 있을 수 있다. 연결 기관으로 부풀리지 않는다.
- 이번 변경은 기관 등록이며 미연결 39개 중앙기관의 수집기 구현을 의미하지 않는다. 공고의 기관분류 전체 정규화도 별도 과제다.
