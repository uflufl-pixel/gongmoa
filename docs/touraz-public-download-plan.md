# 투어라즈 공개 파일 기반 수집 설계

조사일: 2026-09-04. 공개 다운로드와 저장 없는 미리보기 구현 단계이며 운영 게시판 수집기 연결 완료가 아니다.

## 확인된 근거

- 공식 안내: https://www.data.go.kr/data/15149556/fileData.do?recommendDataYn=Y
- 데이터명: 한국관광공사_투어라즈 공고공모 목록. CSV, 무료, 이용허락범위 제한 없음.
- 안내 필드: 상태, 기관명, 제목, 신청기간, 담당부서, 등록일, 게시글 링크.
- 위 허락을 본문·첨부 전체의 재배포 허락으로 확대하지 않는다.
- 포털 메타데이터는 수정일 2025-09-25, 626행, 수시(1회성 데이터)로 안내된다. 현재 내려받는 파일의 최신성·행 수를 보장하지 않는다.
- 공식 화면: https://touraz.kr/announcementList
- 공개 버튼은 `downloadCsv('/fnct/ps/announcementList/getCsvPssrpList?tabMode=ktoip', fileName, title)` 호출.
- 직접 GET 검사: HTTP 200, `text/csv;charset=UTF-8`, 본문 0바이트. 버튼은 GET이 아니었다.
- 공식 `_common.js`의 `downloadCsv`/`ComSubmit` 확인: POST form으로 `fileName=투어라즈 공모 목록 공공데이터 개방`, `title=투어라즈 공모 목록`, `isComsubmit=1` 전송. 별도 로그인·쿠키 없이 202,101바이트 UTF-8 CSV 확보.
- 실제 파일: 922행, 7열, 10개 기관. 한국관광공사 776행/지역기관 146행. 원문 상태 접수 5, 대기 1, 종료 916. 최신 등록일 2026-08-31. 모두 공모사업 건수는 아니다.
- 원문 링크는 암호화된 키 대신 숫자 `pssrpSeq` 제공. 922행 중 중복 ID/격리 행 0. 1709 상세에서 같은 숫자 ID와 제목 확인. 장기 안정성은 추가 관찰한다.
- `POST /api/touraz-preview`: 고정된 공식 다운로드만 사용하고 검증·기관별 집계·후보 표시를 반환. D1 쓰기 없음, 저장 0/검증 완료 0. 일정 시각은 null 유지. 감축 대조 완료 전 정기 수집/등록하지 않는다.
- API 제공 여부와 별도 유관기관 탭의 재이용 범위는 미확인이다.

### 원문 확인 표본

https://touraz.kr/announcementList/pssrpView?pssrpSeq=1709 에서 `2027 무장애 관광환경 조성 사업 공모 실시` 상세를 비로그인으로 확인했다. 신청자격은 광역·기초자치단체, 접수기간은 2026-09-07~09-30이다. 지자체 1:1 매칭이 필수이며 열린관광지 국비 1개소당 2.5억 원, 연계성 강화 3년간 국비 최대 40억 원으로 안내한다. 선정규모는 2027년 예산 확정에 따라 변경될 수 있다. 분야별 양식을 작성하여 공문과 우편 **둘 다** 제출한다. 첨부 안내서의 추가 조건과 마감 시각은 미검증이며 앱 검증 완료로 아직 반영하지 않았다.

후속 교차검토: 상세의 구조화된 신청기간에는 00:00~23:55 시각이 있으나 공문·우편의 실제 도착/소인 기준은 첨부 확인 전 확정하지 않는다. 공통 팝업에 다른 공고의 2026-05-15 15:00 안내가 있으므로 본문 전체 정규식으로 접수기간을 추출하지 않는다.

### 분류·상태 보완

- 인턴 개인 모집은 제외하되 `인턴십 지원사업`과 `참여기업 모집/공모`가 함께 있는 제목은 후보로 유지한다. 채용·결과 공고 제외 규칙은 계속 우선한다. 지원금 내용과 자격 검증을 마친 뜻은 아니다.
- `sourceState`는 원문 그대로 보존하고 `receptionState`를 별도로 계산한다. 한국시간 기준 시작 전 upcoming, 마감 다음 날 closed, 마감 당일 unknown(시각 미확인)이다. 원문 종료는 closed, 기간 중 원문 대기는 unknown으로 유지한다.
- 2026-09-04 후속 공식 대조 완료: https://www.korea.kr/common/download.do?fileId=198545088&tblKey=GMN 의 HWPX(section0~3 및 별첨 문체부 표)에 한국관광공사는 명시되지 않았다. 코레일관광개발은 별개 기관으로 명시돼 있다. 원본 SHA-256: `3999395e16414f26016399bebc16b3f8ff4c6cfe5367c97b275037e5cfcf0005`. 메인과 서브에이전트가 독립 대조했다. 이번 발표 대조로 인한 보류를 해제하며, 향후 개편 가능성을 부정하지 않는다.
- `POST /api/touraz-sync`로 한국관광공사만 저장 연결. 초기에는 미마감 후보만 저장하고 기존 ID는 종료·수정도 추적한다. 누락 행을 삭제하거나 마감시키지 않는다. 과거 전체 공고와 지역기관 공고는 자동 적재하지 않는다.
- 실행 경로는 개별 수집이며 정기 배치에는 아직 포함하지 않았다. 미리보기는 계속 저장 0건이다. 날짜 정밀도와 원문 대기를 API/UI까지 전달해 기간 안의 대기를 접수 중으로 오인하지 않는다.

## 제품 방향

공개 목록 파일을 한 번 가져와 목록 페이지 반복 호출을 줄이고, 신규·변경 후보에만 상세 검증을 수행한다. 파일 전체 행 수는 공모사업 수나 검증 완료 수로 표시하지 않는다.

1. 공식 다운로드 방식 확인 및 실제 파일 샘플 확보.
2. 파일의 열·인코딩·식별자·최신 등록일 확인. 재다운로드 전후 동일 공고 ID 안정성 확인.
3. 저장 없는 미리보기: 전체 행, 기관별 행, 지원사업 후보, 제외 사유, 날짜 미확인, 중복/오류 수.
4. 감축 보류 기관 필터 적용. 기관명은 정확한 기관 ID/확인된 별칭으로 연결하며 미확정 기관은 격리.
5. 검증된 ID 기반으로 신규·변경 행만 기존 upsert 경로에 반영.
6. 사업 목적·신청대상·지원내용·신청방법을 공식 상세에서 확인한 건만 검증 완료로 승격.

지자체·개인·예비창업자·자영업자의 참여기회가 목적이다. 목록에 기업명이 보인다는 이유로 개인 불가로 단정하거나, 관광 공모전·심사 이벤트를 지원사업으로 자동 분류하지 않는다.

## 수집 안전장치

- 다운로드 실패·빈 파일·필수 열 변경 시 기존 자료 유지. 누락 행만으로 삭제·마감하지 않는다.
- 날짜만 제공되면 날짜 정밀도를 유지하고 23:59 같은 시각을 만들지 않는다. 원문 상태와 계산 상태를 구분한다.
- 제목/행 번호/파일명으로 ID를 만들지 않는다. 상세 URL의 검증된 고유 식별자가 없으면 저장 보류.
- CSV 따옴표 안 쉼표·줄바꿈을 처리하고 파일/행/셀 크기를 제한한다. 수식·외부 링크를 실행하지 않는다.
- 같은 파일 재처리·행 순서 변경은 신규 삽입 0건이어야 한다. 정규화된 업무 필드만 변경 해시에 포함한다.
- 현재 upsert는 순차 저장이므로 원자적 일괄 저장이라고 표시하지 않는다. 실행 ID, 파일 해시, 삽입/변경/실패 수를 기록해 재실행한다.
- 초기 제안 빈도는 하루 1회이며 공식 제공 주기가 아니다. 정상 파일 확보·운영정책 확인 후 결정한다.
- 정상 다운로드가 안 되면 반복 호출을 멈추고 수동 공식 파일 가져오기를 대안으로 둔다. 로그인·접근통제를 우회하지 않는다.

## 출시 기준

- 실제 파일 샘플과 필수 열 계약 확보.
- 같은 파일 반복, 행 재정렬, 동일 ID 제목/기간 수정, 상충 중복 ID, 잘못된 날짜/URL, 빈 파일, 중간 저장 실패 후 재처리 테스트 통과.
- 기관 감축 대조 및 원문 ID 안정성 확인.
- 가져오기 성공과 사업 검증 성공을 UI와 실행 결과에서 분리.
- 운영 연결 전 실제 다운로드 최신성과 상세 URL 표본 확인.
