# 한국사회적기업진흥원 사업공고 연결

2026-09-05 구현. 공식 홈페이지의 공개 사업공고 분류(게시판·분류 10002)를 첫 페이지만 POST 조회한다. 계정·로그인·비공개 API 키는 사용하지 않는다.

- 목록: https://www.socialenterprise.or.kr/homepage/bbs/board.do?bsIdx=10002&menuId=822
- 홈페이지가 사용하는 공개 목록 응답: `/homepage/bbs/ajax/boardList.do`
- 등록 기관 `public-009`, 수집기 `socialenterprise-board`, 기존 정기 수집 batch 3에 포함.
- 첫 샘플: 고정 공지 1 + 일반 목록 10. 측정기업·준법 교육 3건 제외, 사업 참여 후보 8건. 운영 수집 결과는 별도로 확인해야 한다.
- 제목·게시일·고유 게시물 ID 등 필요한 필드만 저장. 원본의 IP·작성자 계정 정보는 저장하지 않는다.
- 접수기간은 원문 확인 전까지 unknown. 게시일, 제목의 축약 날짜, 화면 표시 종료일 99991231을 접수일로 변환하지 않는다. 후보를 검증 완료 사업으로 승격하지 않는다.
- 분류 변경·유효하지 않은 날짜·중복 ID 내용 충돌·페이지 구조 변경은 파서 오류로 처리한다. 목록에서 사라졌다는 이유로 기존 공고를 삭제하지 않는다.
- 최초 점검용 POST `/api/socialenterprise-sync`는 요청 파라미터 없이 이 기관만 실행한다.

공공기관 정비계획 공식 HWPX(2026-09-03)의 4개 XML 섹션에서 한국사회적기업진흥원/사회적기업진흥원 이름이 발견되지 않아 현재 보류 대상에 추가하지 않았다. 향후 정비계획 변경은 재확인이 필요하다.
