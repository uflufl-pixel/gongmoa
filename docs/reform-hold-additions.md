## 별도 대기·재확인

- 공공기관 지정요건 해소: 건설산업교육원, 스마트건설교육원, 영남건설기술교육원, 한국실명예방재단, 한국간호교육평가원, 중소벤처기업인증원, 한국산학연협회, 여성기업종합지원센터, 한일산업기술협력재단. 공공기관 수집 범위 재확인까지 신규 연결 보류하되 법인 폐지·통합으로 표시하지 않는다.
- 중소벤처기업연구원은 경제인문사회연구회 소속 변경만으로 통폐합으로 판정하지 않는다.
- 자회사 개편을 모기관 전체 통폐합으로 확대하지 않는다(중진공·기보 등).
- 물산업 관련 기능 통합을 유관 모기관 전체 통합으로 확대하지 않는다.
- 기관명 매핑은 아직 후보 341개 전체 ID 대조 완료가 아니다. 109는 이 표 행 수나 폐지 법인 수가 아니며 후보 수에서 단순 차감하지 않는다.
