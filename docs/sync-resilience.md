# 2026-09-03 수집 지연 보완

- 기관 조사, 수집 지연 진단, 파서 검토를 별도 에이전트가 읽기 전용으로 수행하고, 사이트 담당자가 코드 통합과 배포를 수행한다.
- 기존 정기 수집은 국고 API 한 날짜의 실패가 전체 결과 저장을 중단할 수 있었다. 이제 국고 API 실패를 해당 출처의 실패 상태로 기록하고 다른 기관의 수집·저장을 계속한다.
- 국고 변경분은 오늘·어제 날짜를 조회한다. 500행 단위, 날짜별 최대 20페이지, 두 날짜 전체 20초 제한이다. 한 날짜/페이지라도 실패하면 부분 결과를 완료로 취급하지 않고 두 요청 모두 중단한다. API 키와 요청 URL은 오류 메시지에 노출하지 않는다.
- 실패한 날짜는 출처 점검 메시지에 남는다. 이 변경은 과거 변경분 재처리 큐를 추가하지 않는다. 이틀 이상 지속되는 실패는 날짜별 보완 수집이 필요하며 최초 전체 스캔 완료만으로 이후 변경분의 완전성을 보증하지 않는다.
- 정기 수집에 딸린 기업마당 상세 보완은 1건만 처리한다. 별도 상세 수집 API의 기본 5건, 기존 payload 보존, 재시도/lease 처리는 유지한다.
- 테스트: 여러 페이지/두 날짜 완주, 공유 시간 제한, 실패 시 동시 요청 취소, 비JSON·페이지 누락, 키 비노출. 전체 처리 시간은 원본 응답과 저장 작업에 따라 달라지므로 60초 이내를 보증하는 변경은 아니다.
