# 한국콘텐츠진흥원 상세정보 보강

2026-09-02: 공식 RSS의 공고를 대상으로 고정된 공식 상세 주소에서 제목, 접수기간, 지원대상, 신청방법을 보강한다. 기존 목록 수집 batch=1 실행 시 최대 5건을 순차 처리한다.

- `접수시작일`, `접수마감일`과 `신청방법`의 명시적 신청/접수기간을 대조한다. 행사기간·문의시간은 사용하지 않는다.
- 명시된 마감 시각은 한국시간으로 저장한다. 요약과 본문 날짜가 다르거나 해석하지 못하면 실패로 기록해 확인 대상으로 남긴다.
- 상시모집·예산 소진·모집 완료 조건은 확정 마감일로 바꾸지 않는다. 실제 상시 입주 공고의 요약에는 12월 31일이 있지만 본문은 상시모집이므로 날짜를 비워 둔다.
- 상세정보는 기존 `notice_details`에 출처별로 저장하고 목록 응답에 합친다. RSS의 축약 제목이나 빈 날짜가 상세정보를 덮어쓰지 않는다.
- 성공 후 24시간, 실패 후 1시간에 재시도 가능하다. 실패해도 마지막 성공 정보를 유지한다. 120초 임대로 중복 실행을 제한한다.
- 외부에서 임의 URL을 받지 않고 검증한 공고 ID만 사용한다. 접근 제한을 우회하지 않는다.
- 이번 보강은 기존 콘텐츠진흥원 수집 공고에 한정되며 전체 공공기관 연결 완료를 의미하지 않는다.
