# 공공기관 신규 수집기 작업 순서

사용자 지시 반영일: 2026-09-04. 다음 기관 선택 전 이 문서를 확인한다.

첨부 전체 대조에서 추가된 대상은 [reform-hold-additions.md](reform-hold-additions.md)를 함께 확인한다. 해당 표의 대상과 흡수 주체 모두 신규 착수 대기 대상으로 적용한다.

## 적용 규칙

1. 개편 대상 여부를 확인한 접근 정상 기관의 실제 공모사업 수집을 우선한다.
2. 접근 불량 기관은 보류한다. 감축계획의 통합·폐지·분리 추진 대상은 현재 신규 수집기 작업 목록에서 제외하고 별도 개편 대기 목록으로 관리한다. 구 기관 수집기를 마지막에 개발하는 것이 아니라, 통합·업무승계 기관이 확정된 뒤 그 기관을 최후순위로 추가한다.
3. 기존 연결과 저장 자료는 유지한다. 신규 개발 우선순위 변경이며 정기 수집 중단이 아니다.
4. 보도·검토·계획 발표·법적 시행을 구분한다. 단순 지방 이전이나 예산 삭감을 통폐합으로 간주하지 않는다.
5. 아래는 공식 설명에 명시된 기관의 1차 목록이다. 발표의 '109개 감축'을 우리 후보 341개 중 109개로 빼지 않는다. 자회사와 미등록 기관도 포함될 수 있다.
6. 자회사·전시관 등 포괄 집단은 신규 착수 전 첨부계획의 개별 대상 여부를 확인한다. 확인 전에는 작업을 보류한다.
7. 등록 JSON 순서는 ID 생성에 쓰이므로 재정렬하지 않는다. 후순위는 작업계획에 적용한다. 개편 완료 후 구 기관·신 기관·업무승계·원문 URL을 매핑하고 동일 공고 이력을 보존한다.

## 개편 대기 목록: 현재 신규 연결 작업에서 제외

2026-09-04 추가 지시로 아래 표의 '최후순위'는 모두 **구 기관 신규 연결 제외 → 통합·승계기관 확정 후 마지막에 추가**라는 의미로 적용한다. 청산 기관은 자동 재추가하지 않고 공모 업무의 승계 여부를 확인한다. 분리 기관은 승계 기관별 공모 업무와 실제 게시판을 확인한다.

사용자가 지정한 계획 원문: https://www.korea.kr/docViewer/skin/doc.html?fn=2ba6b3179abaead09a2697f58af83664&rs=/docViewer/result/2026.09/03/2ba6b3179abaead09a2697f58af83664

이 목록은 첨부계획 전체 기관과 기존 후보 ID의 매핑 완료 목록은 아니다. 미대조 기관은 감축 대상이 아니라고 단정하지 않고 신규 착수 전 원문 대조를 필수로 한다. 문서 뷰어는 본문 텍스트를 제공하지 않았으나 후속 조사에서 공식 HWPX의 전체 section0~3 XML을 추출해 기관표를 대조했다.

추가 대조 근거: https://www.korea.kr/common/download.do?fileId=198545088&tblKey=GMN (2026-09-03 관계부처합동 첨부계획).

## 별도 관찰

- 공항 관련 기관: 공식 설명은 지방공항 활성화 추진 후 통합 여부 재검토이다. 확정 통합으로 표시하지 않는다. 중복개발 위험을 줄이기 위해 인천국제공항공사(public-120), 한국공항공사(public-130)의 신규 연결은 잠정 후순위로 둔다.
- KIAT·NIPA·KEITI: 통폐합 관련 과거 보도만으로 후순위 처리하지 않는다. 기존 연결은 유지한다.
- 경기도: 포괄 검토 보도만으로 모든 산하기관을 통폐합 확정 대상으로 만들지 않는다. 구체 대상 확인 후 추가한다.

## 다음 착수 기준

미연결 기관의 개편 대상 여부 확인 → 대상이면 개편 대기 목록으로 제외, 비대상이 확인되면 공개 목록 접근 확인 → 본문 공모요건 검증 → 수집기 구현. 한국농업기술진흥원은 후보이며, 개편 첨부계획 대조를 통과한 뒤 착수한다.

통합기관 재추가 조건: 공식 명칭·법적 시행 또는 업무승계 확인, 공식 홈페이지·공모 게시판 확인, 구 기관 ID와 새 기관의 승계 관계 기록, 중복 공고 병합 기준 검증. 이 조건 충족 후 다른 비대상 기관 연결을 우선 완료하고 최후순위로 착수한다.
