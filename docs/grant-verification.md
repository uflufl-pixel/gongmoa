# 참여 기회 중심 수집·검증 (2026-09-04)

목적: 지자체, 개인, 예비창업자, 자영업자·소상공인 등이 참여 가능한 정부사업을 찾도록 돕는다. 발행기관 유형과 신청자격은 다르다. 기업 수혜 모집만을 포털 전체의 기준으로 삼지 않는다.

## 현재 구현

- 제목 수집 자료는 검토 후보. 본문 목적·대상·지원내용·신청절차를 확인한 감사 기록만 본문 확인 목록에 표시한다. 기존 승인·수집시각·상세 파싱 성공만으로 승격하지 않는다.
- 원문 식별자·제목·수집자료 해시 일치 및 감사 후 7일 이내 조건을 적용한다. 현재 감사 1건은 KOSME CBAM 1351이다.
- API에서 해당 고정 상세 URL만 8초 제한으로 다시 읽어 본문 해시를 대조한다. 변경·응답 실패·구조 오류 시 후보 유지. 재조회가 실패해도 자료를 삭제하지 않는다. 현재 본문만 검사하며 첨부파일 변경 감시는 후속이다.
- 열린 화면도 매분 만료를 재계산한다. 후보가 확인 목록을 대체하지 않는다. 확인된 신청대상은 검색에도 반영한다.
- 공모 유형 확인과 접수 중 여부는 독립이다. 모르는 기간·금액·자격은 추정하지 않는다.
- 근거 기록은 버전 관리된 소스에, 수집 자료는 기존 D1에 보존한다. 대규모 감사 DB와 첨부 문서 파서는 후속 작업이다.

## 대상별 확인 대기 조사

- 개인: [KEITI 에코스타트업 39846](https://www.keiti.re.kr/site/keiti/ex/board/View.do?bcIdx=39846&cbIdx=277). 사업자등록 없는 예비창업자 포함. 공식 이미지 alt에서 요건 확인. 2026-03-03 마감이므로 현재 모집으로 표시 금지. 최신 목록 수집 범위 밖이며 아직 감사 등록·별도 저장 안 됨.
- 지자체: [에너지공단 융복합지원 안내](https://www.knrec.or.kr/biz/introduce/new_engy/intro_cvg.do?gubun=C). 지자체/공공기관 주관 컨소시엄. 일반 사업안내는 연도별 모집공고가 아니므로 바로 저장하지 않는다. 해당 연도 모집문서 추가 확인.
- NIPA 16921: 목적·대상·지원은 확인, 신청절차는 첨부 대조가 필요하여 후보 유지.

신규 기관 착수는 [통폐합 후순위 정책](collector-priority.md)을 적용한다. 신규 기관 수보다 신청 가능한 대상과 확인된 근거의 범위를 성과로 측정한다.
