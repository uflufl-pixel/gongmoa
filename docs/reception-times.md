# 접수기간 정규화 보강

- 대전 공모 목록의 명시적인 접수기간 필드만 읽어 applicationFrom/applicationTo 및 opensAt/closesAt으로 저장한다.
- 원문 HH:mm을 한국시간으로 해석하여 보존한다. 접수 마감시각이 18시이면 자정까지 열려 있다고 판정하지 않는다.
- deadlineLabel에 원문의 전체 기간을 보존하고 카드에 KST 시각을 표시한다.
- 불가능한 날짜, 24시 이상, 역전 기간, 모집 완료 조건은 임의 날짜로 치환하지 않는다.
- 일반 고시공고의 게시일은 접수 시작일로 복사하지 않는다. 이번 보강은 기존 대전 출처에 한정되며 다른 기관의 접수기간은 별도 원문 확인이 필요하다.
