## 후속 구현 우선순위

1. 기업마당 상세 페이지를 제한된 개수씩 수집하고 기존 공고 ID 기준으로 보강한다. 최초 보강·재시도 체크포인트를 별도 유지한다.
2. 소관부처/지자체와 수행기관을 분리하고 접수기간의 원문 조건을 보존한다.
3. 기존 opensAt은 출처에 따라 게시일 또는 신청 시작일이므로 일괄 applicationFrom 복사 금지. 각 출처의 필드 의미를 확인해 정규화한다.
4. 경남 상세 페이지는 이번 웹 조회 도구에서 열리지 않아 구조 확인 미완료. 출처 자체 장애로 단정하지 않는다.
5. 국고 전체 스캔 완료 후 포털과 원문 ID 대조. 이미 지나간 페이지의 기존 공고 상세정보 보강은 별도로 수행한다.

이 문서는 점검 결과와 구현 우선순위이며 위 후속 보강이 이미 배포되었다는 의미는 아니다.
