### 후속 발견

공식 목록에 '투어라즈 공고·공모 목록 다운로드 (공공데이터개방)' 기능이 안내되어 있다. 공공데이터포털 데이터 15149556에서 CSV·무료·이용허락범위 제한 없음을 확인했다. 직접 GET은 빈 응답이었으나 공식 버튼의 POST 방식으로 922행·10개 기관 CSV를 확보했다. 숫자 pssrpSeq 링크를 제공하며 1709 상세 정상 조회도 확인했다. 저장 없는 미리보기 기능을 구현했고 감축 대조와 등록 정책 검증 전 게시판 자동 등록은 하지 않는다. API 제공 여부나 본문·첨부 재배포 허용까지 단정하지 않는다. 상세 설계는 [공개 파일 수집 설계](touraz-public-download-plan.md)를 참고한다.

목록에 '2027 무장애 관광환경 조성 사업 공모 실시'(2026-09-07~09-30, 대기)가 있다. 후속 숫자 ID 상세 조회에서 광역·기초자치단체 신청자격과 지자체 1:1 매칭 지원 및 공문/우편 동시 제출 방식을 확인했다. 첨부 조건과 마감 시각은 미확인이다. '관광공모전 대국민 온라인 참여 심사 이벤트'는 제목에 공모전이 있어도 지원사업 후보로 자동 승격하지 않는다.
