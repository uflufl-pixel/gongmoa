# 검색 결과 신뢰도 표시

- contentHash가 seed-로 시작하는 초기 임시 자료는 운영 목록 응답에서 제외한다. 저장된 원본 행·관심목록은 삭제하지 않으며, 실제 수집으로 검증된 자료는 계속 표시한다.
- 첫 로딩과 통신 오류 때 예시 공고를 실제 결과 대신 보여주지 않는다. 오류에는 다시 불러오기 버튼을 제공한다.
- 확인 범위 패널은 사용자 제외 항목을 뺀 현재 로드 목록을 분모로 소관기관·접수 날짜·조건부 접수·전체 예산의 확인 건수를 표시한다. 전국 공고 수집률이나 모든 상세정보의 완성률로 표현하지 않는다.
- 출처 수는 서버 등록 데이터에서 계산한다. 기관 기준정보 출처인 정부24는 공고 수집 출처 수에서 제외한다.
- 최근 수집 기록을 출처별 가장 최신 기록 하나로 정리한다. 12시간 이상 지난 결과는 재확인 필요로 표시한다. 접근 성공과 전체 수집 완료는 별개다.
- 수동 수집 실패 시 오류를 알리고 마지막 표시 목록을 유지한다.
