# 중앙기관 직접 수집 연결 1차

## 3차: 농촌진흥청

2026-09-02 공식 사이트맵 https://www.rda.go.kr/sitemap.do 의 공지사항 링크를 확인했다. 최신 1페이지 10행에서 공모전·산업체협력연구 공모 2건을 추출했다. `rda-board`를 batch 1에 포함한다. 제목·작성일 셀과 게시판 코드 `ancmtt`, 프로그램 `nei_ancmttEntry`, `dataNo`를 검증하고 면허시험·선정결과는 제외한다. 과거 전체 목록이나 현재 접수 중 여부까지 검증한 것은 아니다. 직접 연결 대상은 10개, 미연결은 35개다.

## 2차: 질병관리청

2026-09-02 공식 정보구독 안내(https://www.kdca.go.kr/kdca/4912/subview.do)에 게시된 공고·공시 RSS 50행에서 공모 후보 27건을 확인했다. `kdca-board`를 batch 0에 연결하며 공식 `/bbs/kdca/51/{id}/artclView.do` 링크만 허용한다. 국민체험단·연수생·면허시험·자격시험은 제외한다. 이전 공고와 재공고가 포함되므로 27개 신규 사업이나 현재 접수 중인 사업 수를 뜻하지 않는다. 접수기간은 원문 확인 상태로 보존한다. 직접 연결 대상은 기존 8개에서 9개로 확대하며 나머지 36개는 미연결이다.

2026-09-02. 기존 4부처에 중소벤처기업부·농림축산식품부·법제처·보건복지부의 수집기를 추가한다. 전체 45개 기관 연결 완료는 아니다.

공식 경로:
- 중기부 RSS 안내: https://tv.mss.go.kr/site/smba/contents/view.do?menuCd=20905000000002024122902&siteCd=smba
- 농식품부 RSS 안내: https://www.mafra.go.kr/home/5327/subview.do
- 법제처 목록 내 RSS 버튼: https://www.moleg.go.kr/menu.es?bid=0010&mid=a10504000000
- 복지부 공식 공지 목록: https://www.mohw.go.kr/menu.es?mid=a10501010000

각 기존 batch 0~3에 한 출처씩 배치해 수동·정기 수집에 함께 포함한다. 목록 구조와 공식 도메인·게시판 식별자를 검증한 뒤에만 성공 처리한다. 공모 후보 0건과 구조 오류를 구분한다. 등록일은 공고일로 저장하며 접수기간으로 추정하지 않는다. 채용·공무원 전입·입찰·용역·결과·포상 등은 제외한다. 목록 수록 범위만 수집하며 과거 전체 페이지 수집 또는 상세 접수기간 보강을 의미하지 않는다.

실제 공식 표본: 중기부 RSS 20행, 농식품부 RSS 50행, 법제처 RSS 49행, 복지부 목록 15행. 법제처·복지부는 이 표본에서 필터 통과 공모 0건이다. 과기정통부 홈페이지는 HTTP 400 Request Blocked 응답으로 보류하며 차단을 우회하지 않는다.

다음 범위: 미연결 기관별 공식 게시판 추가 확인, RSS 없는 사이트 개별 파서, 페이지 범위 확대와 본문 접수기간 보강. 기관 등록 45개와 연결 상태는 API에서 별도로 확인한다.
