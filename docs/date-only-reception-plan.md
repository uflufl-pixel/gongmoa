# 마감일만 확인된 공모의 운영 반영 기준

2026-09-04 구현·테스트 완료. 날짜형 Reception 및 16431 감사 연결, 운영 배포 대상이다. 기존 정확시각형을 유지하고 미확인 시작일 허용은 이번 범위에서 구현하지 않았다(16431은 양쪽 날짜가 확인됨).

문제: KOAT 16431은 9월 4일 마감일만 공지했다. 날짜만 있는 자료에 23:59:59를 만들어 공식 시각처럼 표시하거나 마감 당일 무조건 접수 중으로 표시하지 않는다.

## 최소 변경 계약

- Reception에 deadlinePrecision: date/time 구분 추가. 기존 정확 시각형은 time과 동일하게 유지.
- 날짜형의 closesAt은 명시적으로 null. 이전 추정 시각이 있다면 API 병합에서 제거.
- 시작일이 미확인이면 null 허용, 임의 시작시각 생성 금지.
- 한국 날짜 기준: 마감일 전(시작일 확인 후)은 open, 마감일 당일은 unknown, 마감일 다음날부터 closed. 본문 확인 여부와 접수 상태는 별개.
- 당일 표시문구는 '마감시각 미확인'. 이미 확인된 기간까지 '미확인'이라 표시하지 않는다.
- advancedSearch unknown 포함 옵션은 유지하되 검색 결과에 포함되었다는 이유로 '접수 중' 배지를 달지 않는다.
- candidate로 되돌아간 공고에는 감사 기반 날짜 보강을 적용하지 않는다.

## 검증

1. 한국 마감일 전날, 당일 00:00/23:59, 다음날 00:00.
2. UTC와 한국 날짜가 다른 경계.
3. 기존 closesAt 제거 및 정밀시각 공고 회귀검증.
4. 불가능한 날짜·역전 기간·미확인 시작일·candidate 처리.
5. KOAT 본문 변경 시 감사 실패 및 날짜 보강 제거.

이 변경과 KOAT16431 본문 감사를 함께 배포한다. 공식 본문 재확인에 성공할 때만 검증 및 날짜 보강을 표시한다.
