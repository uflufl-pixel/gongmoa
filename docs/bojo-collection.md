# 국고보조금 전체 수집

공식 명세: https://www.data.go.kr/data/15156853/openapi.do

## 확인 결과
- 사업연도는 필수이고 공고수정일은 선택 조건이다.
- 2026년 날짜 조건 없는 소량 실조회에서 totalCount=196595를 반환했다. 이는 일반 보조사업 및 결합 행을 포함한 원본 행 수이며 공모 건수가 아니다.
- 공고수정일 20260101 소량 조회는 0건이었다. 수정일 조건을 '이후 전체' 조건으로 가정하지 않는다.

## 구현
- GET /api/bojo-backfill: 올해 진행 위치 조회.
- POST /api/bojo-backfill: 날짜 조건 없이 500개 원본 행을 조회하여 공모를 선별하고 저장한 뒤 체크포인트를 전진.
- 5분 실행 잠금으로 동시 전체 수집을 제한한다. 요청이 중단되면 잠금 만료 후 같은 페이지부터 재시도한다.
- 원본 페이지 수와 응답 행 수가 맞지 않으면 체크포인트를 전진하지 않는다.
- 일반 사업, 마감 공고는 신규 등록하지 않는다. 정기 수집의 마감 분리 로직은 유지한다.
- 화면의 시작·이어받기는 최대 10페이지씩 처리한다. 완료 전에는 전체 수집 완료라고 표시하지 않는다.
- 기존 최근 이틀 변경 조회도 여러 페이지를 처리하도록 보완했다. 20페이지 초과는 성공으로 숨기지 않고 오류를 반환한다.

## 남은 검증과 제한
- 최초 전체 페이지 처리 및 포털 국고 조회 결과 대조는 별도 완료 확인이 필요하다.
- 제공처의 정렬·스냅샷 고정 보장이 확인되지 않았으므로 페이지 완료가 절대적 무누락을 보장하지 않는다.
- 자동 증분 수집의 마지막 성공 날짜 기반 복구, 전년도 이월 공모, 지방 공모는 후속 구현 범위다.
- 전체 수집은 올해 1회 스캔이다. 완료 이후 정기 변경 조회는 기존 수집 경로를 사용한다.
