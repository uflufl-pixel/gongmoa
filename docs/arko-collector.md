# 한국문화예술위원회 사업공모 연결 (2026-09-05)

공식 사업공모 게시판 `https://arko.or.kr/board/list/4013?bid=463&sf_icon_category=cw00000019` 첫 페이지를 조회한다. 통합플랫폼의 유관기관 전체 목록은 가져오지 않는다.

- 수집기 arko-board, 기관 public-188. 정기 batch 1 및 파라미터 없는 POST `/api/arko-sync`에 연결.
- 공식 HTML 10행 중 신규 후보 3건: CRL3578 공연예술대관료지원, CRL3577 칠레 레지던시, CRL3575 크라우드펀딩 챌린지.
- 신규 종료 공고는 제외, 기존 ID의 종료 상태는 추적. 기존 공고를 목록에서 사라졌다는 이유로 삭제하지 않는다.
- 공식 연결 원문의 docid를 안정 ID로 사용하고 추적 파라미터는 제거한다. 외부 도메인·다른 기관·상충 중복·잘못된 날짜·상태는 파서 실패 처리.
- 게시판은 진행중이지만 접수기간은 상세/첨부 감사 전 null, 상태 unknown. 후보를 검증 완료로 표시하지 않는다.
- CRL3578은 위원회 목록 9/16, 연결된 아트누리 상세 9/15로 충돌. 이번 연결은 어느 날짜도 확정하지 않는다. 공고문 첨부 대조 후 별도 검증 필요.
- 공식 개혁계획 HWPX 전체 section0~3의 한국문화예술위원회·문화예술위원회·예술위원회·아르코·ARKO 대조 0건. 한국문화예술교육진흥원은 별도 기관이다. 향후 개편 변경은 재확인한다.

운영 접속과 실제 저장 건수는 배포 후 별도 검증한다. 로컬 HTML 파싱 성공은 운영 수집 성공을 의미하지 않는다.
