# 공모 상세검색

- 기본 키워드·기관유형·지역 검색에 분야, 접수 상태, 정렬을 결합한다.
- 상세 조건은 소관부처 → 수행·공고기관, 사업연도, 지원대상 키워드, 공고/접수기간, 공고 전체 지원예산(만원 입력)이다.
- 기간은 선택 범위와의 겹침으로 검색하며 공고기간을 접수기간으로 대체하지 않는다.
- 미확인 포함 옵션은 연도·상태·기간·예산에 적용한다. 확인된 불일치는 포함하지 않는다.
- 접수 상태는 한국 날짜 기준. 시작/종료가 모두 확인되어야 접수 중으로 판단한다. 저장된 마감 상태는 우선한다.
- 빠른 검색: 확인된 접수 중, 오늘부터 7일 이내 접수 마감, 최근 7일 최초 수집. 최초 수집일은 원문 게시일과 다르다.
- API는 저장된 마감 공고도 반환한다. 과거 공고 전체 수집을 의미하지 않는다.
- BOJO 원문 필드 JRSD_NM, BSNSYEAR, PBLANC_BEGIN_DE/END_DE, RCEPT_BEGIN_DE/END_DE, SPORT_BGAMT, REQST_RCEPT_MTH_CN을 별도 저장한다. 없는 값은 null이다.
- 기존 저장 공고는 재수집 전까지 새 상세 필드가 미확인이다. 다른 출처의 상세 필드 정규화 및 기존 공고 보강은 후속 작업이다. 소관부처가 없는 기관에 추측으로 관계를 부여하지 않는다.
- 검증: 검색 단위 테스트, 타입 검사, 배포 빌드. 새 마이그레이션은 nullable 컬럼만 추가하며 기존 데이터를 삭제하지 않는다.
