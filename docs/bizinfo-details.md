# 기업마당 상세정보 보강

- 공식 공개 상세 페이지에서 소관부처·지자체, 수행기관, 신청기간, 사업개요 첫 지원대상 항목, 신청방법을 읽는다. API 인증키가 필요하지 않다.
- notice_details에 원문 기반 정보를 별도로 저장하고 /api/notices 응답에 합친다. 일반 목록 수집이 상세정보를 덮어쓰지 않는다.
- GET /api/bizinfo-details: 대상·성공·실패·재시도 가능 건수. POST: 최대 5건 순차 보강.
- 정기 수집 batch=0 완료 뒤에도 최대 5건 보강한다. 성공 자료는 24시간 후 재확인, 실패는 1시간 후 재시도한다. 임대 잠금으로 중복 요청을 방지한다.
- 실패·필수 항목 누락·잘못된 날짜는 기록하고 기존 성공 자료를 보존한다. 자동 페이지 이동은 허용하지 않는다. 고정 기업마당 도메인과 검증한 공고 ID만 요청한다.
- 날짜가 없는 모집 완료·예산 소진·상시 조건은 텍스트로 보존한다. 접수 중으로 임의 판정하지 않는다. 예산과 사업연도는 본문에서 추측하지 않는다.
- 기존 시드 공고처럼 PBLN_ 공식 ID가 없는 항목은 보강 대상에서 제외한다.
- 원문 날짜에 시간이 명시되지 않은 경우 일 단위 검색만 지원한다. 실제 신청 가능 여부·조건은 원문을 최종 확인한다.
