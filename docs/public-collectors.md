## 한국산업기술진흥원 (KIAT)

- 기존 registry ID `public-251`, 공식 도메인 `kiat.or.kr`. 공식 FAQ와 ALIO 검색에서 산업통상부 소관 위탁집행형 준정부기관을 확인. 후보 JSON의 산업통상자원부 표기는 과거 명칭이며 전체 명단 갱신으로 오인하지 않는다.
- 공식 목록 `https://www.kiat.or.kr/front/board/boardContentsListPage.do?board_id=90`의 공개 조회 요청을 사용한다. 고정된 AJAX 경로로 board_id=90, 첫 페이지 10건을 POST 조회한다. 리디렉션을 거부하고 10초 제한을 적용한다.
- 32자리 원문 식별자를 보존하며 목록 10행에서 후보 7건을 선별한다. 기술·투자 수요조사와 포상은 제외한다. '독일 등 유럽 진출 희망 중견기업 지원사업 선정 공고'는 공식 상세에서 신규 신청 안내임을 확인하여 정확히 일치하는 제목에만 제외 규칙 예외를 적용한다.
- 게시일과 신청기간을 분리한다. 목록 날짜는 일자 단위이며 마감시각 원문 확인을 표시한다. 종료일 다음 날부터 마감 처리되도록 기존 날짜 범위 규칙을 사용한다. 첫 공고 상세에는 18시 마감이 있으나 이번 목록 수집은 모든 상세 시각을 추출하는 기능을 포함하지 않는다.
- 전체 게시물 2,598건 중 첫 페이지 범위다. 전체 이력 또는 모든 접수 중 사업의 완전 수집을 의미하지 않는다. 후속으로 제한적 페이지 순회와 상세 시각 보강이 필요하다.

## 정보통신산업진흥원 (NIPA)

- 기존 registry ID `public-031`, 공식 도메인 `nipa.kr`. ALIO 검색상 과학기술정보통신부 소관 기타공공기관. 후보 JSON의 위탁집행형 준정부기관 유형은 구 정보다. 원본 후보 목록의 순서를 변경하지 않는다.
